Featured Project Experience

AI Automation Project

Restaurant Order Management AI Agent

AI Agent + Telegram Integration + Order Processing + Google Sheets Sync + Automated Notifications

An intelligent agent that receives restaurant orders via Telegram, confirms details with customers, notifies the kitchen, and logs data for inventory tracking.

Overview

An AI-powered restaurant assistant designed to fully automate the order-taking process over Telegram. The agent is equipped with the restaurant's knowledge base and menu. It interacts with customers, answers their inquiries using the provided data, takes their orders, and confirms the final details with them.

Project Workflow

Once the customer confirms the order, the agent performs the following automated actions:

  • Kitchen Notification: Sends an automated message to the chef containing the customer's name, phone number, and exact order details.
  • Inventory Tracking: Logs the identical order data into a Google Sheet to help the management team track inventory and monitor daily sales seamlessly.
